## 简介

DO-IT-Now 是一个以提升个人与团队执行力为目标的任务管理应用示例，使用 TypeScript 编写，代码结构清晰、易于扩展。适合作为学习 TypeScript + 前端工程化、快速原型开发或作为待办类应用的基础模板。

## 主要特性
- 使用 TypeScript 开发，代码可维护性高
- 任务的创建、编辑、删除
- 支持优先级与标签（示例）
- 简洁的用户界面（可替换为项目真实 UI 描述）
- 本地持久化（或接入远程存储）

> 注：以上特性根据仓库实际实现调整；如果有其他功能（例如同步、用户登录、通知等），建议补充到此处以便用户了解。

## 快速开始

先决条件：
- Node.js（推荐 >=16）
- npm 或 yarn

克隆仓库并安装依赖：

```bash
git clone https://github.com/ky1421737671/DO-IT-Now.git
cd DO-IT-Now
npm install
# 或者
# yarn install
```

本地开发（带热重载）：

```bash
npm run dev
# 或者
# yarn dev
```

构建（生产环境）：

```bash
npm run build
# 或者
# yarn build
```

运行测试（如果仓库包含测试）：

```bash
npm test
# 或者
# yarn test
```
